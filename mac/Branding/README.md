# Branding

- `openlab-logo.png`: the openLab logo, master copy (1254 × 1254, transparent background).
- `openlab-logo-1024.png`: the same at 1024 × 1024, the source for the app icon. `mac/openLab/Assets.xcassets/AppIcon.appiconset` holds it scaled with `sips -z <n> <n>` to 16, 32, 64, 128, 256, 512 and 1024 px; regenerate those when the logo changes.
