# Engine test code allowed to read the wall clock or wait with recv_timeout, checked by scripts/check-repo.sh:
# `path | reason` exempts the clock reads (Instant::now, .elapsed(), SystemTime) of a file, and
# `path@recv_timeout | reason` only its recv_timeout (a hang guard or bounded poll); one never excuses the
# other. Either exempts the whole file for that kind, so a new read of it is not caught: keep the files small.
# Same rules as scripts/debug-assertions-allowlist.txt: a reason is `permanent: ...` quoting code in
# backticks, or cites the open issue (#N) that removes the use; an entry whose file no longer has that
# kind of use in test code fails the check, so delete it with the fix.
# Test code means a tests/ directory, a tests.rs, or an item under #[cfg(test)] (also all(test, ..) and
# any(test, ..)).
# Real-time gates are the point of their tests and run only as ignored, release-mode jobs.
