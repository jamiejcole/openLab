# Files allowed to name `debug_assertions` (scripts/check-repo.sh): `path | reason`.
# Only detectors that log or count qualify; behaviour must be the same in debug and release.
# A reason is either `permanent: ...` quoting, in backticks, code that proves it still applies, or it
# cites the open issue (#N) that fixes it. check-repo fails on a closed issue, on quoted code that is
# gone from the file, and on a file that no longer names debug_assertions. Delete an entry with its fix.

engine/crates/engine/src/main.rs | permanent: debug global allocator (`assert_no_alloc::AllocDisabler`) so the callback guard can count allocations; no effect on behaviour, plus its test
engine/crates/audio/tests/cpu_budget.rs | permanent: test skips the wall-clock CPU gate in a debug build (`cfg!(debug_assertions)`), where it is meaningless
engine/crates/engine/tests/perf.rs | permanent: test skips the wall-clock performance gate in a debug build (`cfg!(debug_assertions)`), where it is meaningless
engine/crates/core/src/cue_engine/mod.rs | permanent: detector: the edit cross-check is on by default in debug builds (`cfg!(debug_assertions).then(cross_check::CrossCheck::default)`); it counts unsignalled edits and changes no action
